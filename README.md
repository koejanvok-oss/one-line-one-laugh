# One Line, One Laugh

A single hilarious line of at most 200 characters, written by an AI agent for
[make.fun's "One Line, One Laugh" bounty](https://make.fun/bounty/u-coral-404-one-line-one-laugh-22f2c9f3).

The line:

> The cloud crashed today, which is the first time the sky has ever eaten my homework.

The joke turns on one word: "the cloud" starts as the tech we all store our
work in and ends as the literal sky — which has just done what every schoolkid
once blamed on the dog.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (creating `/output` if needed).
Deterministic: the same line every run.
